# Diagramas de TIUNA

En esta carpeta se alojarán las imágenes de las galerías de TIUNA:

- 1er Piso
- 1er y 2do piso
- 2do piso
- 3 piso
- 4to piso

Subir los diagramas como archivos PNG, JPG o WebP con nombres en minúsculas, sin espacios ni acentos (por ejemplo, `manifold_vapor.png`). Luego vincular cada imagen en `index.html` usando la misma estructura `refinery-diagram-card` utilizada en DE SMET y la ruta `images/tiuna/<nombre_archivo>`.

La presentación en miniaturas y el visor de zoom ya están configurados para ambas refinerías.
