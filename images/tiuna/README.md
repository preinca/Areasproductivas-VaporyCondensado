# Diagramas de TIUNA

Esta carpeta contiene las imágenes utilizadas en la pestaña **TIUNA** del dashboard.

## Organización por piso

| Piso | Diagrama | Nombre de archivo |
| --- | --- | --- |
| 1er piso | Conjunto de tuberías e instrumentación | `conjunto_tuberias_instrumentacion.png` |
| 1er y 2do piso | Sistema de distribución de vapor de blanqueo | `distribucion_vapor_blanqueo_dos_niveles.png` |
| 2do piso | Intercambiador de calor del sistema de blanqueo (E-103) | `intercambiador_calor_e103.png` |
| 2do piso | Manifold de distribución de vapor de blanqueo | `manifold_distribucion_vapor_blanqueo.png` |
| 3er piso | Alimentación de vapor del sistema de blanqueo | `alimentacion_vapor_sistema_blanqueo.png` |
| 3er piso | Intercambiadores de calor del sistema de blanqueo | `intercambiadores_calor_blanqueo.png` |
| 4to piso | Sistema de blanqueo: válvula de control de vapor y reactor | `valvula_control_vapor_reactor_blanqueo.png` |

**Para publicar:** subir los siete PNG a esta misma carpeta `images/tiuna/`, sin crear subcarpetas, respetando exactamente sus nombres. La sección de TIUNA en `index.html` ya está configurada y las imágenes se visualizarán automáticamente con la galería y el visor de zoom compartido.

El código de Apps Script no requiere cambios.
